# Weekly Briefing Format — Canonical Specification

This skill defines the single format used for all weekly company briefings in the Sales Intelligence Platform. Every briefing — whether generated on-demand from the Weekly Report tab or batch-generated by the Sunday cron — MUST follow this specification exactly.

## Source of truth

The prompt lives in `backend/app/services/weekly_briefing_builder.py`. There is only one briefing generator. Do not create a second one.

## Generation flow

1. **Sunday 10pm EST**: `POST /api/reports/weekly/refresh-all` runs
2. Curated company news is regenerated for all companies (from that week's signals)
3. Curated industry news is regenerated for all three sectors
4. Weekly briefings are generated for each company using `build_weekly_briefing()`
5. The briefing reads from the **curated news cache** (not raw signals) and compares against the **annual baseline**
6. Results are saved to the `weekly_reports` table and cached for the week

## NO_OPPORTUNITY gate

Before writing a full briefing, the LLM must decide: does this week's news create a meaningful consulting opportunity? If not, output only:
```
NO_OPPORTUNITY: [one sentence explaining why nothing is actionable this week]
```

## Card JSON (first line of output)

```
CARD_JSON: {"headline": "...", "confidence_score": 8, "confidence_tier": "Act Now", "opportunity": "...", "taxonomy_tag": "exact S& capability name", "lead": {"name": "...", "role": "...", "email": "..."}, "action": "..."}
```

- `confidence_tier` must be one of: `Act Now` (8-10), `Strong Signal` (6-7), `Monitor` (3-5), `Noted` (0-2)
- `taxonomy_tag` must be an exact capability name from the S& taxonomy for the company's sector

## Report sections (in order)

### 1. Title
```
# {company_name} — Weekly Briefing ({week_start} to {week_end})
```

### 2. Baseline Delta
What CHANGED this week vs. the annual baseline? Which themes were accelerated, contradicted, or are new? If nothing changed: "No material change to the baseline trajectory this week."

### 3. This Week's Signals
For each curated company signal:
```
- **[Taxonomy Tag] Signal title** — why it matters. Suggested action.
```

### 4. Industry Context
Top 2-3 industry signals that affect this company, with category and relevance.

### 5. Financial Cross-Reference
Connect this week's signals to the financial baseline and peer benchmark. Only reference financials when they connect to this week's news. Do NOT restate the financial position.

### 6. The Opportunity
THE specific S& engagement this week's intelligence points to.
- What capability? (exact taxonomy name)
- Why this week? (what new evidence)
- Concrete Phase 1 scope
- Who should pitch it?

### 7. Who Should Act
- GRP: name, email, role
- S& lead / account team: name, email, role
- Client contact: name, title, approach angle
- Salesforce context if any

### 8. Confidence Assessment
Score each dimension as X/2:
- Signal Strength: X/2 — (0=single unconfirmed, 1=top-tier source, 2=multiple corroborating)
- Financial Evidence: X/2 — (0=no connection, 1=directional alignment, 2=specific metric supports it)
- Timing Urgency: X/2 — (0=no forcing function, 1=general window, 2=specific deadline/trigger)
- Taxonomy Fit: X/2 — (0=no capability match, 1=indirect, 2=direct obvious fit)
- Baseline Alignment: X/2 — (0=one-off, 1=loosely related, 2=accelerates/contradicts documented theme)

**Total: X/10** — [tier label]. One sentence justification.

### 9. Recommended Actions
3-5 bullet points of specific actions for this week, each naming a person.

## Tone and length

- Under 1000 words
- Every claim tied to evidence
- Specific — name people, cite numbers, reference baseline themes
- Written for a Strategy& partner, not a general audience
- Persona: "Strategy& intelligence director"

## Data inputs (all fed into prompt)

1. S& capability taxonomy for the company's sector
2. Annual baseline themes
3. Curated company news (from cache — taxonomy-tagged, with "why it matters")
4. Curated industry news (from cache — categorized with partner relevance)
5. Financial analysis + peer benchmark
6. PwC relationship data (GRP, account team)
7. Salesforce pipeline
8. Client contacts
9. Enriched intelligence (MCP sources)

## When modifying the briefing

- Do NOT change section headers or their order
- Do NOT change the CARD_JSON schema
- Do NOT change the confidence scoring dimensions
- Do NOT create a second generator — all briefings come from `weekly_briefing_builder.py`
- If adding a new data source, add it as input context, not as a new section
